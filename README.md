# Controle Financeiro Pessoal

Projeto pessoal desenvolvido em **Python e SQLite**, com o objetivo de criar uma aplicação desktop para organização e acompanhamento das finanças pessoais.

O sistema busca facilitar o controle de receitas, despesas, cartões e lançamentos financeiros.

## Tecnologias utilizadas

- Python
- SQLite
- CustomTkinter
- Git e GitHub

## Funcionalidades e estrutura

- Cadastro e gerenciamento de categorias
- Gerenciamento de cartões
- Controle de lançamentos financeiros
- Modelagem de banco de dados relacional
- Organização do código em Models, Repositories, Services e UI

## Objetivo do projeto

Aplicar conhecimentos de programação, banco de dados, regras de negócio e desenvolvimento de interfaces, evoluindo gradualmente para uma aplicação de controle financeiro mais completa.

**Status:** Em desenvolvimento. Algumas funcionalidades e módulos ainda estão em implementação e testes.
